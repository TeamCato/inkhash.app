# 0009 Der Server ist die Quelle, das Gerät hat einen Cache

Status: angenommen

## Entscheidung

„Nirgendwo sonst“ heißt: kein iCloud, kein zweiter Anbieter. Das Gerät speichert lokal, damit Schreiben ohne Netz geht, und gleicht nur mit dem eigenen Server ab.

## Warum

Eine Notiz-App, die im Zug nicht aufgeht, verfehlt den Zweck. Die Sicherung bleibt das Verzeichnis auf dem Server.

## Nicht

Keinen zweiten Sync-Pfad danebenlegen, auch nicht „nur als Backup“.
